# IdleBound Wiki

https://jxlife.github.io/idlebound-wiki/

Every page here is generated from the game's data by `tools/wiki/build.js` in the game repo, and published by its **Wiki** GitHub Action whenever the data changes. Don't edit these files by hand: the next build replaces them.

To build it yourself from the game repo: `node tools/wiki/build.js ../idlebound-wiki`
